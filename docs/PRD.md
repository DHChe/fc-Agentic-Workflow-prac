# PRD: SlipScan

## 목표
중소기업 담당자가 영수증·카드명세서 PDF/이미지를 올리면, Claude API가 가맹점·일자·금액·부가세·항목을 추출해 대시보드에서 바로 확인하고 보관할 수 있게 한다. 수기 입력을 없애는 것이 목적이다.

## 사용자
페르소나, 저니, 유스케이스 전체는 `docs/USER_FLOWS.md`에 있다. 요약:
- 1차 사용자: 중소기업의 경비 처리 담당자(경리·총무). 직원들이 제출한 영수증과 법인카드 명세서를 정리한다.
- MVP는 개인 계정 단위다. 회사·팀·직원 권한 개념은 없다.
- 시연 대상: 외부 이해관계자. 미리 만든 시연 계정 하나로 어느 기기에서든 같은 데이터를 본다.

## 핵심 기능
1. 랜딩 → 대시보드: `/`에서 제품 소개와 CTA. 로그인 상태면 `/dashboard`로 redirect.
2. 인증: 운영자가 Supabase에서 발급한 계정으로 이메일+비밀번호 로그인 또는 Google 로그인, 로그아웃. 공개 회원가입은 없다. 비로그인 상태로 `/dashboard/**` 접근 시 `/login`으로 보낸다.
3. 업로드·분석: 파일 1개 업로드 → Claude 분석 → 결과 저장 → 상세 화면 이동. 분석 중 진행 상태를 표시하고, 실패 시 원인 메시지를 보여준다.
4. 대시보드: 내 분석 목록(최신순, 최근 100건)과 요약 카드(전체 건수, 이번 달 합계 금액). 요약은 그 목록에서 계산한다. 이번 달 합계는 문서 일자가 이번 달인 KRW 항목의 합이고, 일자를 읽지 못한 항목은 제외한다. 항목 클릭 시 상세로.
5. 상세: 추출 결과(문서 유형, 가맹점, 일자, 합계, 부가세, 카테고리, 품목/거래 표), 원본 미리보기(서명 URL), 삭제. 신뢰도 0.6 미만이면 "확인 필요" 배지, 판독 불가(`unknown`)면 안내와 삭제 유도.
6. 라이트/다크 테마 토글. 기본값은 시스템 설정.
7. 결과 수정: 상세에서 가맹점·일자·합계·부가세·카테고리를 인라인으로 고쳐 저장. 수정된 항목은 "수정됨" 표시. 품목·거래·문서 유형은 수정하지 않는다.
8. CSV 내보내기: 대시보드 목록(최근 100건)을 분석 1건 = 1행으로 저장. Excel에서 한글이 깨지지 않게 UTF-8 BOM.

## 입력 제약
- 형식: `application/pdf`, `image/jpeg`, `image/png`, `image/webp`. HEIC 미지원 (시연 전 JPEG로 변환).
- 크기: PDF 20MB 이하(100페이지 이하), 이미지 5MB 이하.
- 한 번에 파일 1개.
- 환불 영수증은 음수 금액으로 기록되며 월 합계에서 차감된다. 수정 폼에서도 음수를 허용한다.

## 추출 결과 스키마 (AnalysisResult)
| 필드 | 타입 | 설명 |
|------|------|------|
| documentType | `receipt` / `card_statement` / `unknown` | 문서 유형 |
| merchant | string / null | 가맹점명 (영수증) |
| date | `YYYY-MM-DD` / null | 거래일 또는 명세서 기준일 |
| currency | string | 기본 `KRW` |
| totalAmount | number | 합계 금액 |
| vatAmount | number / null | 부가세. 표기 없으면 null |
| category | `식비`/`교통`/`숙박`/`소모품`/`접대`/`통신`/`기타` / null | 지출 분류 |
| items | `{ name, quantity, amount }[]` | 영수증 품목. 없으면 빈 배열 |
| transactions | `{ date, merchant, amount, category }[]` | 카드명세서 거래. 없으면 빈 배열 |
| confidence | number 0~1 | 판독 신뢰도 |
| notes | string / null | 판독 불가 항목, 주의사항 |

## MVP 제외 사항
- 회사·팀·직원 권한, 승인 워크플로우
- 품목·거래·문서 유형 편집, 재분석
- 품목·거래 행 단위 내보내기, Excel(xlsx) 형식, 회계 시스템 연동
- 공개 회원가입, 앱 내 초대·역할 관리, 비밀번호 재설정(운영자가 대시보드에서 변경), Google 외 소셜 로그인
- 이미지 자동 축소, HEIC 변환, 다중 파일 일괄 업로드
- 비동기 큐 (분석은 요청 안에서 동기 처리, 최대 60초)
- 목록 페이지네이션·검색·월별 필터 (최근 100건만 표시하고 요약 카드도 그 기준)
- 사용량 한도와 남용 방어(요청 출처 검사, 업로드 파일 내용 검사, 모델 원본 추출값 보존). 공개 가입이 없어 사용자는 전부 운영자 발급 계정이다
- OpenAI 등 다른 LLM 구현체 (인터페이스만 둔다)
- 다국어 (한국어 고정)

## 디자인
- 방향: 매일 쓰는 업무 도구. 마케팅 화면이 아니라 표와 숫자가 주인공.
- 테마: 라이트 기본 + 다크 토글. 무채색 + 포인트 색 1가지(blue-600).
- 상세 규칙은 `docs/UI_GUIDE.md`.
